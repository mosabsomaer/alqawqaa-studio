🚀 To Get Started:

1. Fix npm permissions:
   sudo chown -R $(id -u):$(id -g) "$HOME/.npm"

2. Install dependencies:
   ./INSTALL.sh

3. Run development server:
   npm run dev

4. Build Windows installer:
   npm run package:win
